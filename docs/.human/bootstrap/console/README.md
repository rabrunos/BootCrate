# Optional Project Console

After the owner selects it at the end of intake and approves materialization, copy only `index.html`, `styles.css`, `console.js` and `preset.js` into the downstream project's `project-console/`. The preset file must match the shared resolver in `../app/preset.js`; template validation checks parity. Do not copy Setup, questions, intake, evals or materialization tools. With Console disabled, do not copy this folder at all. Removing it later cannot break the product.

Open `project-console/index.html` as a local file. It imports the stable profile, optional ignored local override, version source, `CHANGELOG.md` version headings and a separately generated delivery preflight per destination. The local check only checks imported inputs, and the history view is not a full changelog parse. It reports the origin and limits of each observation. It can download a sanitized ephemeral snapshot and a small `preset.json` for placement in ignored `.local/config/preset.json`. It never reads credentials, product source or the full checkout, and cannot silently write files or publish. The executor reads and applies the same task/local/project/default preset precedence through its native settings.

A local profile import is only a UI preview, not a substitute for full schema/finalization validation. Delivery preflight is a preview, not live provider proof. Direct browser write is intentionally absent until a file-mode/permission compatibility spike demonstrates it across the supported browsers; the download plus ordinary file tool is the portable fallback. Validate keyboard order, error/status announcement, zoom/reflow and at least one screen-reader/browser combination before claiming accessibility conformance.
