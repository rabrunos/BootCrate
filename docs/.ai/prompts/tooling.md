# Tooling Task Template

Start from `base.md` and define only relevant items:
- developer workflow being improved;
- supported environments;
- inputs/outputs/exit behavior;
- deterministic validation;
- dry-run/negative paths;
- local/private-data boundaries;
- compact machine-readable output when useful;
- explicit prohibition on real publication during validation.

Tooling work normally tracks as a GitHub Task, not a separate Issue type.
